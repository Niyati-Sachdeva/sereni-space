🌿 Sereni Space

Sereni Space is an AI-powered wellness and mindfulness application built with Flutter. The app is designed to help users improve emotional well-being through journaling, guided meditation, breathing exercises, sleep wellness practices, and personalized AI-generated reflections.

✨ Features
📖 Mindful Journaling
Create and save personal reflections.
Persistent local storage using Hive.
Clean and distraction-free writing experience.
🤖 AI-Powered Insights
Integrated Gemini AI for reflection analysis.
Generates personalized emotional insights.
Provides actionable wellness suggestions based on journal entries.
🧘 Guided Meditation
Curated meditation sessions.
Detailed meditation experience screen.
Session timer for focused practice.
🌬 Breathing Exercises
Structured breathing techniques for relaxation.
Quick access from the home screen.
🌙 Sleep Wellness
Sleep preparation guidance.
Simple mindfulness practices for better rest.
🎨 Personalization
Light/Dark theme support.
Theme preference persistence using Hive.
😊 Mood-Based Recommendations
Select your current mood.
Receive tailored wellness suggestions.
